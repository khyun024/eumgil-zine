규칙 · 군도 스타일 가이드

모든 섬이 같은 바다에 떠 있으려면

여러 사람이 만든 게임을 하나의 지도로 묶는 규칙입니다. 게임 페이지 자체는 각자의 모습을 유지하되, 지도 위 표현과 지도로 돌아오는 길은 이 규칙을 따릅니다.

  1. 그라디언트, 반투명, 블러 그림자를 쓰지 않습니다. 그림자는 먹 단색으로 오른쪽 아래 4px 오프셋만.
  2. 초록은 '현재 위치·당신'을 가리킬 때만 씁니다. 장식이나 강조에 쓰지 않습니다.
  3. 질감은 빗금(세로 1px 해칭)과 물결선 두 가지뿐입니다.

2. 선과 형태

  1. 윤곽선은 먹 2px, 세부는 1.5px. 완벽한 직선·원 대신 살짝 흔들린 손그림 선.
  2. 섬 = 둥근 덩어리 + 아래쪽 물결 그림자 2겹. 마을 = 빗금 벽에 흰 지붕. 나무 = 먹 실루엣.
  3. 말풍선 = 흰 사각형 + 꼬리. 깃발 = 아래가 파인 흰 배너. 이 둘이 '설명'과 '거점'을 뜻합니다.
  4. 둥근 모서리, 카드 그림자, 아이콘 폰트, 이모지를 쓰지 않습니다.

3. 글자

제목 · Do Hyeon — 에움길 군도
지도 라벨 · Gaegu Bold — 비탈길의 그림자
본문 · Gowun Dodum — 스물한 명이 이태원 골목에서 채집한 규칙으로 만든 섬들입니다.
  1. 크기 스케일: 13 / 15 / 18 / 22 / 28 / 40. 이 사이 값은 쓰지 않습니다.
  2. 작품 이름은 〈 〉로 감쌉니다. 장소는 "이태원 ○○"처럼 동네 + 지점으로 씁니다.
  3. 본문 한 줄은 66자 안쪽. 숫자는 표나 큰 숫자 칸에만.

4. 움직임

  1. 물결은 40초에 한 타일 흐릅니다. 섬은 마우스를 올리면 4px 떠오릅니다.
  2. 배는 클릭한 섬까지 1.2초 동안 항해한 뒤 말풍선이 열립니다. 움직임은 한 번에 하나.
  3. 움직임 줄이기 설정이 켜지면 물결·배 흔들림을 멈춥니다.

5. 섬 규격 (게임을 지도에 연결하는 법)

참여자 게임 하나는 아래 항목 하나로 지도에 등록됩니다. 항목만 채우면 섬 모양, 마을, 나무는 지도가 이름을 씨앗으로 자동으로 그립니다.

  "place": "이태원 비탈길",

  "url": "https://…/games/slope-shadow/",
  "thumb": "thumbs/slope-shadow.png",   // 4:3, 없으면 빗금 자리
  "houses": 3                  // 1~4, 게임의 규모 감

  1. 썸네일은 4:3, 플레이 화면 캡처. 지도에서는 먹 2도(먹 + 종이)로 변환해 표시합니다.
  2. 각 게임 페이지 왼쪽 위에 "← 군도로" 태그를 답니다. 종이 배경, 먹 테두리, Gaegu Bold. 이것이 서로 다른 게임을 한 바다로 묶는 최소 규칙입니다.
  3. 게임 페이지가 자체 색을 쓰더라도, 첫 화면에 장소 이름과 규칙 한 줄을 이 지도와 같은 문장으로 노출합니다.
