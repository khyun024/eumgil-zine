# 에움길 군도 · 디자인 규칙

〈수상한 산책클럽〉 결과 웹페이지(인터랙티브 지도)와, 여기에 연결되는 참여자 게임 페이지가 공유하는 규칙입니다. 첨부된 손그림 지도(노란 바다 위의 섬·마을·말풍선·깃발) 톤을 기준으로 삼았습니다.

## 1. 색 — 여섯 가지만 쓴다

| 이름 | HEX | 쓰임 |
|---|---|---|
| 바다 | `#FBE9B4` | 페이지 바탕, 표 머리 배경 |
| 물결 | `#E6C266` | 물결선, 섬 아래 파문, 보조 선 |
| 섬 | `#E9A93A` | 섬 채움, 강조 배경(선택된 버튼·칩·주석) |
| 먹 | `#1E1B16` | 모든 선, 글자, 나무 실루엣, 배 |
| 종이 | `#FFFFFF` | 말풍선·패널·두루마리, 지붕 |
| 지금 여기 | `#1F7A45` | '당신(현재 위치)' 표시와 키보드 포커스에만 |

- 그라디언트, 반투명 채움, 블러 그림자를 쓰지 않는다. 그림자는 먹 단색 오른쪽 아래 4px 오프셋 하나.
- 질감은 두 가지뿐: 세로 빗금(1px 해칭, 집 벽·빈 썸네일)과 물결선.
- 초록은 장식·강조에 쓰지 않는다.

## 2. 선과 형태

- 윤곽선 먹 2px, 세부 1.5px. 완벽한 직선·원 대신 살짝 흔들린 손그림 선(섬 윤곽은 씨앗 난수로 생성).
- 섬 = 둥근 덩어리 + 아래쪽 파문 2겹(물결색). 마을 = 빗금 벽에 흰 지붕. 나무 = 먹 실루엣.
- 말풍선(흰 사각형 + 꼬리) = "설명". 깃발(아래가 파인 흰 배너) = "거점".
- 금지: 둥근 모서리, 카드 그림자(blur), 아이콘 폰트, 이모지.

## 3. 글자

| 역할 | 서체 | 크기 |
|---|---|---|
| 제목 | Do Hyeon | 28 / 40 |
| 지도 라벨·손글씨 UI(버튼, 칩, 캡션) | Gaegu Bold | 13 / 15 / 18 / 22 |
| 본문 | Gowun Dodum | 15 |

- 크기 스케일 13 / 15 / 18 / 22 / 28 / 40 밖의 값은 쓰지 않는다.
- 작품 이름은 〈 〉로 감싼다. 장소는 "이태원 ○○"처럼 동네 + 지점.
- 본문 한 줄은 66자 안쪽. 숫자는 표나 큰 숫자 칸에만.

## 4. 움직임과 시점

지도 전체가 Three.js(WebGL) 3D 장면이다. 조명 없이 여섯 색만 쓰는 '종이 오리기' 방식: 모든 면은 단색 또는 빗금이고, 윤곽선은 먹색 뒤집힌 껍질(inverted hull)로 그린다. 그림자·조명·안개는 쓰지 않는다.

| 요소 | 3D 표현 |
|---|---|
| 바다 | 무한 평면 + 셰이더 물결선(물결색, 배를 따라 이동) |
| 섬 | 모래턱 → 본섬 → 언덕 3단 돌출. 윗면 섬색, 옆면 세로 빗금, 파문 2겹 |
| 마을 | 빗금 벽 상자 + 흰 지붕 + 먹 문. 나무는 먹 원뿔·구 |
| 항로 | 먹 점 520개가 실제 물길을 따라 놓임. 회차 지점은 흰 원반 |
| 배 | 먹 선체(흰 난간·점), 좌현 마스트, 눈 문양 돛, 밧줄, 뱃머리 등 |
| 하늘 | 종이색 배경, 수평선 먹 선, 해·구름 스프라이트(조타 시점에서만) |
| 글자 | 3D에 넣지 않고 HTML 라벨을 투영해 얹는다 |

두 가지 시점만 있다.

| 시점 | 언제 | 화면 |
|---|---|---|
| 해도(위에서 본 지도) | 정박 중, 섬 상세를 읽을 때, 드래그·휠로 둘러볼 때 | 카메라가 60° 위에서 북쪽을 향해 내려다본다. 표지·범례·상세 패널이 보인다 |
| 조타(1인칭) | 방향키·WASD·터치 패드로 배를 움직일 때, 섬을 클릭해 자동 항해할 때 | 카메라가 배의 고물 갑판(높이 약 3)에 붙어 뱃머리 너머를 본다. 배가 롤링·피칭·상하로 흔들리면 카메라도 함께 흔들린다. 해·구름이 켜지고 먼 섬 라벨은 숨긴다 |

- 시점 전환은 0.9초. 배가 멈춘 채 2.6초가 지나면 해도로 돌아온다. Esc·'해도 보기'로도 돌아온다.
- 섬에 배를 대면(섬 반지름 78% 안) 자동으로 상륙해 해도로 바뀌고 말풍선·상세 패널이 열린다.
- 자동 항해는 섬을 피해 돈다(반지름 1.25배 + 70 안에 들어오면 반대쪽으로 조타).
- 오프닝(약 30초): 출항 카드가 뜨고 1.8초 뒤(또는 '출항' 클릭) 파프리 스튜디오 항구에서 배가 느리게(평소 속도의 2/3) 떠난다. 조타 시점으로 섬 사이 물길(26개 경유점)을 따라 5회차 지점 다섯 곳을 차례로 지나며, 지점마다 회차 캡션(번호·이름·한 줄)이 뱃머리 위에 뜬다. 항구로 돌아오면 해도로 당겨져 군도 전체가 드러난다. 아무 곳이나 누르면 건너뛴다.
- 캡션은 항해 중 항로 지점 110 단위 안에 들어올 때마다 다시 뜬다(5.2초 뒤 사라짐).
- 물결은 40초에 한 타일 흐른다. 섬은 hover 시 4px 떠오른다. 배·뱃머리는 1.5초 주기로 흔들린다. 움직임은 한 번에 하나.
- `prefers-reduced-motion`이 켜지면 오프닝을 건너뛰고 물결·배 흔들림을 멈춘다. 시점 전환은 유지된다.

## 5. 섬 규격 — 게임을 지도에 연결하는 법

참여자 게임 하나 = 아래 항목 하나. 항목만 채우면 섬 모양·마을·나무는 `id`를 씨앗으로 자동 생성된다.

```json
{
  "id": "slope-shadow",
  "title": "비탈길의 그림자",
  "author": "참여자 이름",
  "cohort": 3,
  "place": "이태원 비탈길",
  "rule": "귀로 들은 단서를 따라 골목의 그림자를 추리한다",
  "desc": "오디오 기반 야외 추리 게임",
  "url": "https://…/games/slope-shadow/",
  "thumb": "thumbs/slope-shadow.png",
  "houses": 3
}
```

- `cohort`: 1~4. 자체 제작 도구는 `"tool"`.
- `houses`: 1~4. 게임의 규모 감(마을 크기).
- `thumb`: 4:3 플레이 화면 캡처. 지도에서는 먹 2도로 변환해 표시. 없으면 빗금 자리.

### 게임 페이지가 지켜야 할 최소 규칙 (각자 만든 페이지의 자유는 유지)

1. 왼쪽 위에 "← 군도로" 태그. 종이 배경, 먹 2px 테두리, Gaegu Bold, 먹 4px 오프셋 그림자.
2. 첫 화면에 장소 이름과 규칙 한 줄을 지도와 같은 문장으로 노출.
3. 게임의 자체 색을 쓰더라도, 위 태그와 문장은 이 팔레트를 따른다.

- 지도(바다)가 전체 화면. 표지·범례·내비·상세 패널은 종이 카드로 위에 뜬다. 오른쪽 아래에 조타 패드(▲◀▼▶)가 항상 있다.
- 항해일지·선원명부·규칙은 지도 위에 덮이는 두루마리(오버레이). 지도를 떠나지 않는다.
- 720px 이하: 범례 숨김, 내비는 아래로, 상세 패널은 바텀 시트.
