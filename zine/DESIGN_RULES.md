# 에움길 진 · 디자인 규칙 (v2, 아날로그·꼴라주)

〈수상한 산책클럽〉 결과 웹페이지와 참여자 게임 페이지가 공유하는 규칙. 룹앤테일 리서치 페이지(크라프트지, 모노 본문, 검은 라벨 제목, 커서 펜 선, 호버 마키, 플립북)를 참조해 "진(zine)"으로 다시 짰다. 데이터와 여덟 지점 구조는 v1(도면)과 같다.

## 1. 색
| 이름 | HEX | 쓰임 |
|---|---|---|
| 크라프트지 | `#E9E2CF` | 바탕 |
| 붙인 종이 | `#F3EEE1` | 도면 시트, 스크랩, 책장 |
| 벽면 | `#E4DCC6` | 투시 공간 |
| 먹 | `#111111` | 선, 글자, 라벨 바탕 |
| 보라 | `#8F89CC` / `#5A54A3` | 웅덩이(완성된 게임), 플레이하기 버튼 |
| 도장 | `#B8321F` | 고무도장 하나 |
| 테이프 | `rgba(226,206,140,.72)` | 종이 고정 |
- 그림자는 종이가 뜬 만큼의 검은 오프셋(2~10px, 불투명도 .16) 하나. 블러 없음. 둥근 모서리는 라벨과 버튼에만.
- 종이 질감은 SVG 노이즈 한 겹(multiply, .22).

## 2. 글자
- 본문·표기: IBM Plex Mono 12.5px. 제목 라벨: 검은 바탕 + 종이색 글자, 둥근 사각(loopntale 방식).
- 큰 글자: Times New Roman + 나눔명조. 표지 마키 26~68px, 책장 제목 22~34px.
- 장식 기호는 일곱 개만: ❪ ❫ ☆ ✶ ⚭ ✹ ➹.

## 3. 종이와 꼴라주
- 모든 패널은 찢은 종이(clip-path 폴리곤, 진폭 5~6px). 살짝 기울이고(±1~2°) 테이프 두 장으로 붙인다.
- 도면 시트 자체도 찢은 가장자리 + 네 귀퉁이 테이프.
- 도면 위 스크랩: 사진 자리 5장(빗금, 캡션 【사진 n】), 인용 쪽지 3장(명조), 고무도장 1개, 라벨 스티커 3장.
- 사진은 4:3, 먹 2도로 변환해 붙인다.

## 4. 움직임과 인터랙션
- 표지: 큰 문장 세 줄이 마우스를 올린 동안만 흐르고, 떼면 감속해 멈춘다(loopntale 방식). 클릭·스크롤·아무 키로 걷기 시작. 9초 뒤 자동 시작.
- 커서가 지나간 자리에 펜 선이 남고 천천히 옅어진다.
- 걷기·시점(평면/보행)·발자국·카메라는 v1과 같다.
- 06 안내서 도착 → 책이 펼쳐지고 23장(표지 + 21팀 + 마지막)이 0.5초 간격으로 넘어간다. 클릭·휠·← →로 직접 넘긴다.
- "두루마리로 ⇄": 같은 내용이 가로 두루마리로 풀린다. 도착 시 자동으로 끝까지 풀리고, 드래그·휠로 되감는다. 선택은 브라우저에 기억.
- 마지막 장 = 플레이하기 ↗ (외부 링크). 08 산책자들 메모지 끝과 우상단에도 같은 링크.

## 5. 게임 등록 규격
v1과 동일(id, title, author, cohort, place, rule, desc, url, thumb). 게임 페이지는 왼쪽 위 "← 진으로" 라벨과 첫 화면의 장소·규칙 문장만 맞춘다.
